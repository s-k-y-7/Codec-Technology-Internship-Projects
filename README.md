# Artificial Intelligence Internship Projects

This repository contains two machine learning projects completed during the 1-Month Artificial Intelligence Internship at Codec Technologies.

## Projects

### 1. Movie Recommendation System

A content-based recommendation system that suggests similar movies using TF-IDF Vectorization and Cosine Similarity.

**Technologies**
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

---

### 2. Customer Churn Prediction

A machine learning model that predicts whether a customer is likely to churn using multiple classification algorithms.

**Algorithms**
- Logistic Regression
- Decision Tree
- Random Forest

**Technologies**
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
